# Constitución de Escuela Clara

Principios que se respetan durante todo el desarrollo, en cualquier feature.

1. **Privacidad de los menores primero.** Solo datos ficticios en el repositorio. Mostrar el mínimo necesario (nombre y salón). Ningún dato de alumnos sale hacia servicios externos sin decisión explícita.
2. **Simplicidad para quien lo usa.** La interfaz es para una coordinadora con poco tiempo: una pantalla principal, lenguaje claro, pocos clics.
3. **Las familias no instalan nada.** El canal es un enlace por WhatsApp.
4. **Notificar no es autorizar.** Un mensaje enviado jamás equivale a una respuesta recibida.
5. **Verificabilidad.** Todo comportamiento tiene un criterio de aceptación comprobable. Sin criterio verificable, no se implementa.
6. **La spec manda.** Ante una discrepancia, se corrige primero la spec y después el código.
7. **Un feature a la vez.** Alcance pequeño y entregable; lo demás queda explícitamente fuera.
8. **Accesibilidad.** Los estados nunca se comunican solo con color; contraste y uso en celular.
